# 40 种设计风格 · 参考图鉴

把 B 站视频[《你一直在寻找的 40 种设计风格名称（更快地找到参考）》](https://www.bilibili.com/video/BV1anQwYZEw2) 里的 **40 种设计风格 + 1 种加映**，整理成一个可以直接双击打开的静态参考站。

**1080P 高清封面 · 上传者中文字幕提炼的内容 · 深浅两套主题 · 零依赖零构建。**

```
style-ref/index.html     ← 双击就能看（不需要服务器、不需要联网）
```

**线上地址：<https://liceses.github.io/design-style-index/>**

发布方式：GitHub Actions 把 `style-ref/` 打包成 Pages 产物（见 [`.github/workflows/pages.yml`](.github/workflows/pages.yml)），推送到 `main` 即自动更新。所以站点文件不必挪到仓库根目录——**发布产物的根目录就是 `index.html`**，而 `dev/`（工具链与字幕文本）不会被发布出去。

---

## 仓库结构

```
├── README.md            本文档（仓库总览）
├── style-ref/           ← 网站本体，可独立拷走使用
│   ├── index.html       页面结构
│   ├── styles.css       深/浅两套主题 + 组件样式（无网络字体）
│   ├── app.js           搜索 / 分组 / 排序 / 详情 / 键盘 / hash 路由 / 主题切换
│   ├── data.js          数据（41 条，由 dev/build_site_data.py 生成）
│   ├── img/             41 张视频原帧（1600×900）
│   │   ├── thumbs/      41 张缩略图（720px）
│   │   └── pd/          31 张 Wikimedia Commons 公开版权补充图
│   └── README.md        ← 完整文档：来源、版权、交互、验证记录
└── dev/                 ← 制作工具链（抽帧、字幕对齐、找公开图、验收）
```

**网站是自包含的**：`style-ref/` 整个目录拷到任何地方、任何静态托管都能跑。

`dev/` 是为了可复现而保留的制作过程记录。里面的脚本写的是本机绝对路径（`D:/developing/webdesign/...`），换机器需要自行调整；另外原始视频（207MB）与中间产物（候选帧、联系表）没有入库，需要时用这些脚本重新生成。

## 这个站有什么

- **41 条**风格（40 正片 + 1 加映「Scrapbook 拼贴手账」），每条配一张从视频里逐帧挑出来的画面
- 详情页有：一句话摘要、**创作者原话**（提炼自上传者自制的中文 CC 字幕，带时间码可点回视频）、**历史来源**、**今天用在哪**、**搜索关键词提示**
- 每张卡片的强调色是从该风格封面图里**提取的主色**，深色与浅色主题各有一版派生色
- 搜索（中英文名 / 特征 / 描述）、分组筛选、三态排序（**视频时间轴** / 名称 / 分组）、随机打开
- 键盘：`←` `→` 翻页、`Esc` 关闭、`/` 聚焦搜索；`#slug` 可直接分享
- **深/浅两套主题**，默认跟随系统，切换后记忆选择；对比度经脚本实测（正文 ≥7:1）

详细的来源说明、版权提示、验证记录都在 [`style-ref/README.md`](style-ref/README.md)。
