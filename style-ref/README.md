# 40 种设计风格 · 参考图鉴

> 把 B 站视频[《你一直在寻找的 40 种设计风格名称（更快地找到参考）》](https://www.bilibili.com/video/BV1anQwYZEw2)（BV1anQwYZEw2）里的 **40 种设计风格 + 1 种加映**，整理成一个可以直接双击打开的静态参考站。
>
> **1080P 高清封面** · **上传者中文字幕提炼的内容** · **深浅两套主题** · 零依赖零构建。

---

## 1. 怎么打开

```
双击 style-ref/index.html
```

不需要服务器、不需要构建、不需要联网（图片全部在本地 `img/` 下）。放到任何静态托管上也能直接用。

## 2. 视频里到底有多少种风格

视频简介给出的时间轴里，风格名从 `Neoclassical`(0:51) 一直到 `Mid Century`(27:58)，**正好 40 种**；在 `28:35` 还有一段标着 **Bonus Style** —— 标题卡上印的是 **Scrapbook Collage（拼贴手账）**。作者自己在字幕里说：*"这严格来说是第 41 种风格，但听起来不如 40 那么好，所以作为额外赠送。"*

所以本站收录 **41 条**：40 种正片风格 + 1 种加映，分组里单独有一组「视频加映」。

风格名一律以**视频标题卡上实际印出的字样**为准（例如标题卡写的是 `NEOCLASSICAL ART`、`BENTO GRID`、`POINTILLISM`，时间轴里则写作 `Neoclassical`、`Bento Box`、`Pointilism`）；差异都记在每条数据的 `videoName` 字段里。

**卡片编号 = 视频时间轴顺序。** 编号 `n` 按 `t`（视频秒数）重新排过，所以默认的「视频顺序」排序、卡片左上角的编号、徽章上的时间码三者是一致的、单调递增的。

## 3. 文件结构

```
style-ref/

├── styles.css      全部样式：深/浅两套 token + 组件样式，无网络字体

├── img/            41 张视频原帧（1600×900，源自 1080P）
│   ├── thumbs/     41 张缩略图（720×406，列表用）
│   └── pd/         31 张 Wikimedia Commons 公开版权补充图（≤1400px）
└── README.md       本文档
```

零依赖、零构建：三个文件 + 一份数据 + 一堆图片，`file://` 协议下全部功能可用（没有用 ES module，避免 `file://` 的跨域限制）。全站体积约 13 MB。

## 4. 内容从哪来（三类，分别标注）

### ① 视频原帧（41 张，全部都有）

按视频时间轴定位到每种风格的段落开头——视频的结构是「标题卡 → 主持人讲解 → 示例图穿插」，真正的示例画面出现在每段 **开头 1–4 秒**。每张封面都是从该窗口里逐帧比对后挑出来的（优先没有压字、不是主持人镜头、不是转场模糊帧的那一张）。

**清晰度**：B 站未登录只给 480P，登录后取到 **1920×1080** 源（AVC，937 kbps，207 MB）。41 张封面全部从 1080P 源按同一时间点重抽，导出为 1600×900。

### ② 上传者字幕（41 条详解，全部都有）

**来源**：该视频带一条 **上传者本人制作的中文 CC 字幕**（`lan=zh-Hans`、`ai_type=0`、作者 mid 就是 UP 主本人、**484 条**），不是 B 站 AI 转写。它逐句翻译了英文原片的旁白，信息量远大于画面。

**对齐方式**：不依赖字幕自身的断句，而是用视频简介里的时间轴做段落边界（`dev/segments.json`），把 `[起点+2s, 下个起点)` 之内的句子归给该风格；起点前 4 秒的句子单独列为「衔接」，因为那往往是上一段的收尾话——这样能避免把上一段的总结安到下一段头上。

**提炼成 4 个字段**（每条都写了，见 `dev/subtitle-facts.json`）：

| 字段 | 含义 | 例（Tenebrism） |
|---|---|---|
| `say` | 创作者原话（清理了口误、玩笑与频道推广） | "这种风格依赖于极端的光影对比，创造出高戏剧性的聚光灯效果…" |
| `origin` | 历史来源与年代 | "起源于 17 世纪的巴洛克绘画，由卡拉瓦乔等艺术家推广。" |
| `usage` | 今天用在哪 | "氛围海报、活动传单、编辑排版、网页设计…" |
| `tips` | 搜索关键词 / 实操提示 | "它更像是一个艺术术语；通常非常强烈、非常阴郁" |

`sayAt` 记下原话在视频里的时间码，详情页可以点回去听那一句。

> 原片是英文视频（作者来自设计工具 **Kittl**，字幕里被音译成 "Kittle/Kiddle"，我在提炼时已还原为 Kittl 并剔除了相关推广）。中文全归上传者翻译。

### ③ 公开版权参考图（31 / 41 个风格有）

从 **Wikimedia Commons** 检索更清晰的公开授权图，逐张目视确认相关性后收录；每张都在详情页注明**标题 · 作者 · 许可协议 · 来源链接**。古典/艺术史类风格很容易找到对得上的图（新古典天顶、巴洛克湿壁画、德绍包豪斯、里加新艺术、伦勃朗《夜巡》、温莎城堡、点彩、蒸汽波落日网格……）。

以下 **10 个风格没有补充图**，因为检索到的候选与风格对不上（例如 `bohemian` 被抓成同名的教堂、`mystical-western` 被抓成"西洋美术馆"、`y2k` 被抓成"Y2K 千年虫计算器"），宁可留空也不硬凑：

`Bohemian`、`Coquette`、`Y2K`、`Kawaii`、`Japandi`、`Mid Century`、`Mixed Media`、`Mystical Western`、`Utilitarian`、`Scrapbook`

> 版权说明：视频原帧与字幕的著作权属于原视频作者（B 站 UP 主「咲喜」，原片为英文视频，作者来自 Kittl）。本站在本地/学习用途下引用，并注明了出处与时间码；若要公开分发，请自行确认授权。Commons 图片按各自许可协议使用（本站用到 CC0 / 公有领域 / CC BY / CC BY-SA / FAL），详情页已附署名与协议链接。

## 5. 交互

| 操作 | 说明 |
|---|---|
| 搜索框 | 匹配英文名 / 中文名 / 特征词 / 描述，空格分词全部命中才算 |
| 分组 chips | 6 个分组（古典与装饰 / 绘画与拼贴 / 现代主义与平面 / 数字与街头 / 柔光与生活 / 视频加映） |
| 视频顺序 / 名称 A–Z / 按分组 | 点「视频顺序」按钮循环切换；**默认按视频时间轴** |
| ☾ 深色 / ☀ 浅色 | 工具条最左侧按钮，一键切换主题 |
| 随机一种 | 从当前筛选结果里随机打开一条 |
| 点卡片 | 打开详情：大图 + 摘要 + **创作者原话** + 来源/用途 + 特征 + 时间码链接 + 上下一种 |
| 复制风格要点 | 把摘要、原话、来源、用途、提示、出处整段复制走 |
| `←` `→` | 详情内翻上/下一种 |
| `Esc` | 关闭详情 |
| `/` | 聚焦搜索框 |
| `#slug` | 可直接分享，例如 `index.html#vaporwave` |

### 深浅主题

- **默认跟随系统**（`prefers-color-scheme`）；点了按钮之后就记住选择（`localStorage: styleref.theme`），不再被系统改回去。
- 首次绘制前就在 `<head>` 里定好 `data-theme`，**不会出现先白后黑的闪烁**。
- 浅色不是把深色反相，而是另一套暖纸感配色（`#f6f5f2` 底 / 白面板 / 深墨字）；图片上的角标为了可读性在两种主题下都保持深色胶囊。
- 对比度经脚本实测：正文 ≥ 7:1、次级文字 ≥ 4.5:1、辅助文字 ≥ 4:1，深浅两套都过。

### 强调色是"从图里长出来的"

每张卡片的强调色用 Pillow 从该风格封面图里**提取主色**。为照顾两套主题，实际生成四个派生色：

- `accent` —— 深色主题用（亮而饱和）
- `accentInk` —— 浅色主题用（同色相压暗，保留源色饱和度性格）
- `tint` / `tintLight` —— 两种主题下卡片图框的底色

## 6. 怎么改内容 / 重新生成

内容与图片分离，改内容不用碰 HTML：

```
1. 改 dev/style-master.json        ← 名称、中文名、分组、特征、一句话摘要
   （要改字幕提炼的内容，改 dev/subtitle-facts.json）
2. 跑 dev/build_site_data.py       ← 重新生成 data.js（重算主色、四色派生、视频顺序编号）
```

要换某张封面：改 `dev/finals.json` 里该风格的秒数，然后

```
node dev/extract-finals.mjs        ← 按秒数重新导出 img/（1600）与 img/thumbs/（720）
```

`dev/` 下的工具链：

| 脚本 | 作用 |
|---|---|
| `fetch-style-video.mjs` | 未登录取 playurl、下载最高可用清晰度（480P）并 remux |
| `fetch-hd-cdp.mjs` | 从**已经开着的**带 `--remote-debugging-port` 的浏览器取登录态，请求 1080P 并下载。**它自己不开浏览器** |
| `fetch-subtitle.mjs` | 匿名尝试取字幕（结论：拿不到，B 站只对已登录请求下发字幕地址）|
| `subtitle-via-cdp.mjs` | 从那个登录窗口取字幕，抓完自动关窗口 + 删配置目录 |
| `align-subtitle.mjs` | 把字幕按视频时间轴切分到 41 个风格段落，输出 `dev/subtitle/by-style.md` 供校订 |
| `extract-candidates.mjs` / `probe-window.mjs` / `dense.mjs` / `window.mjs` / `fine.mjs` | 各种抽帧方式（按段落比例、按固定偏移、按固定步长） |
| `extract-covers.mjs` / `extract-finals.mjs` | 导出封面候选 / 导出最终封面 |
| `sheets.py` / `review_pd.py` | 把候选图拼成带标签的联系表，供人工挑选 |
| `fetch-commons.mjs` | 抓 Wikimedia Commons 候选图（串行节流 + 指数退避） |
| `build_site_data.py` | 合并内容 + 主色 + 字幕要点 → `data.js` |
| `check-assets.mjs` | **静态完整性校验，不启动浏览器**。日常改完跑这个 |
| `verify-live.mjs` | **线上站点验收**：逐 URL 打状态码，并用线上 `data.js` 反查全部 113 张图是否可访问 |
| `verify-site.mjs` / `cdp-shot.ps1` | 真机交互验收与截图（会拉起 headless Edge；两个脚本都会在运行前/后清理自己的残留实例） |

## 8. 已知限制

- **视频原帧里可能带原视频的信息**：有些封面保留了视频自己压上去的风格名（例如 `BAROQUE`、`VICTORIAN`）。这是视频原本的呈现方式，不是截图失误——这类帧在视频里就是"标题卡"。
- **卡片里的一句话摘要是整理者编写的**；详情页的「创作者原话 / 来源 / 今天用在哪」才是上传者字幕的内容，并标了时间码。两者在页面上是分开呈现的。
- **字幕是中文翻译**，个别专有名词照原样保留了上传者的译法（如把 Kittl 译成 "Kittle"、把 "Mid-century" 译成"中世纪"），我在提炼字段时做了还原，但 `say` 字段保留原话风格、只做语句通顺处理。
- 补充图只覆盖 31/41 个风格，且是"名称对得上"的公开素材，可能与视频里展示的示例不完全一致。
- 站点本身无后端，因此没有收藏/笔记持久化；要留痕请用 `#slug` 链接。
- 源视频（1080P，207 MB）留在 `dev/style-video/video-1080.mp4`，字幕原文留在 `dev/subtitle/`，方便以后重抽或复核。
